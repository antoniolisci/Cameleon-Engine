# Chantier Constellium — Socle doctrinal

Le dossier Constellium regroupe les documents doctrinaux liés au futur chantier de calibration adaptative de Caméléon Engine.

Ces documents décrivent :
- les limites structurelles des indicateurs comportementaux actuels ;
- les profils opératoires comme régimes de lecture contextuelle ;
- les transitions de régime et la dérive progressive ;
- l'architecture de mémoire comportementale ;
- les garde-fous anti-complaisance non calibrables ;
- la philosophie du moteur adaptatif futur.

## Documents

| Fichier | Rôle |
|---|---|
| `audit-indicateurs-comportementaux.md` | Audit structurel des 5 patterns comportementaux — limites, problèmes, classification |
| `profils-operateurs-constellium.md` | 5 régimes opératoires — faux positifs, faux négatifs, garde-fous par profil |
| `transitions-operatoires-et-derive-progressive.md` | Transitions, dérive progressive, mémoire comportementale, stabilité de profil |

## Statut

Aucun document présent ici ne constitue une implémentation active.

Le chantier Constellium est considéré comme :
- post-MVP ;
- post-Phase 2 V2 ;
- dépendant de la stabilisation complète du moteur comportemental actuel.

## Phrase fondatrice

> La calibration adapte l'interprétation. Elle ne blanchit jamais les dérives.
