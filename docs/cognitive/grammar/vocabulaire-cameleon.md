# Vocabulaire Caméléon — Grammaire officielle

**Statut :** document vivant — à enrichir par concept validé, jamais par liste exhaustive.

---

## Rôle de ce fichier

Fixer les mots. Pas tous les mots — les mots qui ont une signification précise dans
le contexte de Caméléon Engine, qui diffèrent de leur usage courant dans le trading,
ou qui peuvent glisser vers un sens interdit si leur nuance n'est pas documentée.

Ce fichier est une contrainte de production. Avant d'écrire un nouveau texte pour le
cockpit — libellé, message de coaching, description d'état — ce fichier est la référence.

---

## Mots autorisés et leur sens exact

Ces mots ont un sens précis dans la grammaire Caméléon. Ils ne sont pas librement
substituables par leurs synonymes courants.

---

**Lecture**
Ce que le cockpit produit. Pas un verdict, pas un signal, pas une recommandation.
Une lecture rend quelque chose visible — elle ne décide pas à la place du trader.

*Usage correct :* "le cockpit produit une lecture de la situation décisionnelle."
*Usage incorrect :* "le cockpit donne une lecture → entrer long."

---

**Retenue**
Posture comportementale active. La retenue est un choix conscient, proportionné,
temporaire. Elle reflète une lecture, pas une peur.

*Nuance :* la retenue n'est pas de l'inaction. C'est de l'action différée sur la
base d'une information lue.
*Ne pas confondre avec :* hésitation (involontaire), paralysie (bloquante), refus (figé).

---

**Défense**
Posture de protection du capital en cours. Active, délibérée. Pas d'urgence —
anticipation d'un contexte dégradé.

*Nuance :* la défense est une posture, pas un signal de danger.
*Ne pas confondre avec :* fuite (réactif et non délibéré), protection d'urgence,
peur du marché.

---

**Contexte**
L'ensemble des conditions dans lesquelles une décision se prend. Le contexte inclut
l'état du marché ET l'état du trader. Les deux sont indissociables dans la lecture
Caméléon.

*Nuance :* le contexte n'est pas une opportunité. Un contexte favorable n'implique
pas une entrée. Il indique que les conditions de lisibilité sont réunies.
*Ne pas confondre avec :* setup (technique, orienté entrée), signal (déclencheur externe).

---

**Alignement**
État où la lecture du marché et l'état comportemental du trader convergent.
L'alignement n'est pas une certitude — c'est une cohérence.

*Nuance :* un trader aligné peut avoir une lecture fausse. L'alignement dit que
la décision a été prise dans un état cohérent, pas qu'elle sera gagnante.
*Ne pas confondre avec :* certitude (il n'y en a pas), conviction aveugle, signal fort.

---

**Friction**
Délai intentionnel introduit par le cockpit pour que la conscience rattrape l'impulsion.
La friction n'est pas une punition. Elle n'est pas un blocage. Elle est toujours
contournable.

*Nuance :* la friction est proportionnelle à la confiance d'exécution — plus la
confiance est basse, plus le délai est long. Pas l'inverse.
*Ne pas confondre avec :* refus (irréversible), verrouillage (binaire), pénalité.

---

**Posture**
Orientation générale du trader à un moment donné — pas une position de marché.
La posture est comportementale (prudence, défense, attente, engagement) et non
directionelle (long, short, neutre).

*Nuance :* la posture informe l'exécution sans la dicter.
*Ne pas confondre avec :* position (technique, sur le marché), biais (directionnel).

---

**Régime**
État stable sur une période. Un régime est persistant — il dure plusieurs décisions,
voire plusieurs sessions. Il est distinct d'une émotion ponctuelle.

*Nuance :* un trader peut traverser un régime de FOMO sans être "impulsif" à chaque
décision. Le régime colore la lecture, il ne la détermine pas.
*Ne pas confondre avec :* humeur (fugace), caractère (permanent), trait de personnalité.

---

**Miroir**
Ce que le cockpit est. Il restitue ce qu'il voit — sans jugement moral, sans
prescription, sans verdict.

*Nuance :* un miroir peut montrer quelque chose de déplaisant. Ce n'est pas une
critique — c'est une information.
*Ne pas confondre avec :* juge (qui évalue), coach (qui prescrit), signal (qui déclenche).

---

**Présence calme**
Signature Caméléon. L'interface n'amplifie pas l'agitation du marché — elle maintient
une lisibilité constante. Quand le marché s'agite, le cockpit ralentit.

*Nuance :* la présence calme n'est pas l'absence d'information. C'est le maintien
d'un espace de lecture stable indépendamment du bruit ambiant.

---

## Mots interdits

Ces mots ne doivent jamais apparaître dans les textes du cockpit, les libellés,
les messages de coaching, ou les descriptions d'état.

| Mot interdit | Raison |
|---|---|
| Signal | Implique un déclencheur externe — le cockpit ne déclenche pas |
| Alerte | Crée une urgence artificielle — contradictoire avec la présence calme |
| Opportunité | Oriente vers l'action — le cockpit oriente vers la lecture |
| BUY / SELL | Direction de marché — hors périmètre |
| Interdit | Trop binaire — la friction remplace le blocage |
| Bloqué | Même raison |
| Verrouillé | Même raison |
| Refusé | Même raison |
| Suspendu | Même raison |
| Optimal | Implique une maximisation — hors doctrine |
| Parfait | Même raison |
| Risque/Récompense | Vocabulaire d'optimisation — hors périmètre comportemental |
| Setup | Vocabulaire technique orienté entrée |
| Breakout | Direction implicite |
| Confirmation | Implique une validation externe que le cockpit ne fournit pas |
| Prédiction | Le cockpit lit — il ne prédit pas |

## Nuances officielles

Ces paires montrent comment deux mots proches ont des sens distincts dans la
grammaire Caméléon. La confusion entre les deux mots est le premier vecteur
de dérive sémantique.

---

**Lecture ≠ Signal**
Une lecture rend lisible. Un signal déclenche une action. Caméléon produit des lectures.
Il ne produit pas de signaux. La différence est architecturale.

**Retenue ≠ Interdiction**
La retenue est un choix actif et réversible. L'interdiction est un blocage externe.
Le cockpit ne bloque jamais — il ralentit et rend visible.

**Défense ≠ Blocage**
La défense est une posture anticipée et délibérée. Le blocage est une contrainte
imposée. Le trader en posture de défense a choisi cette posture.

**Contexte ≠ Opportunité**
Un contexte favorable dit que la lisibilité est bonne. Une opportunité dit d'agir.
Le cockpit produit des contextes — pas des opportunités.

**Alignement ≠ Certitude**
L'alignement est une cohérence entre état et lecture. La certitude est une conviction
sur le résultat. Le cockpit ne produit jamais de certitude.

**Friction ≠ Punition**
La friction est proportionnelle à la confiance, temporaire, et toujours contournable.
Une punition est sanction d'un comportement passé. La friction ne punit pas — elle ralentit.

**Profil ≠ Diagnostic**
Le profil comportemental décrit une tendance observée sur un corpus de données.
Un diagnostic implique une pathologie et une prescription de traitement. Le cockpit
ne diagnostique pas.

**Régime ≠ Caractère**
Un régime est un état temporaire observable sur une période. Le caractère est un trait
permanent. Un trader en régime FOMO n'est pas "un trader FOMO" — il traverse un régime.

**Calme ≠ Inaction**
La présence calme de l'interface n'est pas de l'absence. C'est un espace de lecture
stable. Le silence dans le cockpit est de l'information, pas du vide.

**Miroir ≠ Validation**
Le cockpit reflète ce qu'il voit — il ne confirme pas que la lecture du trader
est correcte. Un miroir ne ment pas, mais il ne valide pas non plus.

---

## Règle de production

Avant d'ajouter un libellé, un message, ou une description dans le cockpit :

1. Le mot existe-t-il dans la liste des mots interdits ? Si oui, reformuler.
2. Le mot existe-t-il dans les mots autorisés ? Si oui, respecter sa nuance exacte.
3. Le mot crée-t-il une attente d'action chez le lecteur ? Si oui, reformuler.
4. Le mot juge-t-il plutôt que de décrire ? Si oui, reformuler.
