\# BUG-001 — Vidéos supprimées encore appelées



\## Problème observé

Erreurs 404 dans la console sur d’anciennes vidéos supprimées.



\## Cause probable

Anciennes références vidéo encore présentes dans le code ou le mapping.



\## Solution prévue

Centraliser les références vidéo et remplacer les anciens chemins.



\## Statut

À traiter plus tard.
