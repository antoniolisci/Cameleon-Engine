# archives — Zone d'archivage

**Statut :** Archive

## Rôle

Conserve les systèmes, modules et documents obsolètes. Rien n'est supprimé — tout ce qui a existé et n'est plus actif atterrit ici.

## Ce qu'on y met

- Anciennes versions de modules supprimés
- Systèmes abandonnés en cours de développement
- Documents de référence périmés
- Essais non concluants mais instructifs
- Sous-projets mis en réserve (ex : `holoworld_reserve/`)

## Ce qu'on n'y met pas

- Fichiers actifs du projet
- Code source en cours d'utilisation
- Fiches de bugs ouverts (→ `bugs_console/`)

## Règles de nommage

```
ARCHIVE_NNN_description.md     ← fiche documentaire
nom_du_systeme/                ← sous-dossier pour systèmes entiers
```

## Sous-dossiers connus

| Dossier | Contenu |
|---|---|
| `holoworld_reserve/` | Réserve conceptuelle Holoworld — en attente ou abandonné |

## Statut du dossier

Archive — en lecture seule sauf ajout de nouvelles archives.
