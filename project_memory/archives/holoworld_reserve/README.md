# holoworld_reserve — Réserve conceptuelle Holoworld

**Statut :** Réserve

## Rôle

Zone de mise en réserve pour le concept Holoworld — idées, systèmes ou modules liés à ce projet parallèle ou à cette vision étendue de Caméléon Engine. Ni actif, ni supprimé.

## Ce qu'on y met

- Documents conceptuels liés à Holoworld
- Systèmes envisagés dans ce cadre mais non implémentés
- Notes de vision ou de roadmap associées
- Références croisées avec Caméléon Engine si pertinentes

## Ce qu'on n'y met pas

- Code source actif
- Bugs ou notes techniques du moteur principal
- Décisions d'architecture validées (→ `architecture_decisions/`)

## Règles de nommage

```
HW_NNN_description.md
```
Exemple : `HW_001_vision_systeme_multi_actifs.md`

## Statut du dossier

Réserve — contenu suspendu. À réactiver si le projet Holoworld reprend vie.
